# 熊猫漫剧

Windows 桌面应用下载与更新仓库。这里只发布使用说明、更新记录及打包成品，不存放开发源码。

## 下载

[下载 Windows x64 免安装版 v0.20.1](https://github.com/qqweiyijianyi/panda-canvas/releases/tag/windows-v0.20.1)

完整解压 ZIP，保留整个文件夹，双击“熊猫漫剧.exe”。不需要安装 Node.js 或启动开发服务器。

## 使用说明

- 支持现有画布及图像、视频工作台界面；模型调用需要自行配置 API 服务和额度。
- 项目保存在本机，浏览器里的项目需先导出 ZIP，再到桌面应用导入。
- 升级时保留本机用户数据，建议先导出项目备份。当前通过本仓库手动下载更新，尚不支持应用内自动更新。
- 软件尚未签名，Windows 可能提示未知发布者。
- GitHub 附带的 Source code 压缩包只有本下载仓库说明；请下载 Release 中的 Windows 软件 ZIP。
